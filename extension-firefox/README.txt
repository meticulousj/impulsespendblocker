Impulse Spend Blocker for Firefox

Install (temporary, for testing):
1. Unzip this file.
2. Open about:debugging#/runtime/this-firefox in Firefox.
3. Click "Load Temporary Add-on..." and pick manifest.json in the unzipped folder.
4. Firefox asks for site access: click the extension icon > "Always allow" on shopping sites (or grant in about:addons > Permissions).

Temporary add-ons are removed when Firefox restarts. For permanent install, submit the ZIP to addons.mozilla.org.
